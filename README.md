# 🚗 Парковочный переполох (Parking Jam Puzzle)

Браузерная 2D-головоломка: нужно освободить выезд и вывести красную машину с
переполненной парковки. Вид строго сверху, играется мышью или пальцем,
одинаково хорошо работает на ПК, планшете и телефоне.

```
npm install
npm run dev      # http://localhost:5173
```

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Дев-сервер Vite (0.0.0.0:5173 — удобно открывать с телефона по локальной сети) |
| `npm run build` | Продакшн-сборка в `dist/` |
| `npm run preview` | Локальный просмотр собранной версии |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | Все тесты (ядро, уровни, генератор, интерфейс) |
| `npm run gen:levels` | Перегенерация 100 уровней в `src/game/levels/generated.ts` |
| `npm run assets:cars` | Пересборка спрайтов машин из `assets/cars-src` в `public/cars` |
| `npm run preview:board` | Оффлайн-превью кадра уровня в PNG (`node tools/preview-board.mjs 12`) |

## Что уже готово (этапы 1–5)

**1. Игровое ядро.** Vite + TypeScript + React + Phaser 3 + Zustand + IndexedDB.
Сетка 6×6 (крупные уровни — 7×7 и 8×8), машины длиной 2 и 3 клетки:
горизонтальные ездят только по X, вертикальные — только по Y, сквозь машины
проезда нет, за границы поля тоже. Уровень пройден, когда целевая машина
упирается в правый край строки выезда.

**2. Уровни.** 100 уровней с ростом сложности: 1–10 обучение, 11–25 легко,
26–45 средне, 46–65 сложно, 66–85 очень сложно, 86–100 эксперт. Уровни 1–5
расставлены руками, 6–100 сгенерированы (`tools/generate-levels.gen.ts`) и
проверены решателем: у каждого есть решение, а `par` — минимальное число ходов.

**3. Интерфейс.** Главное меню, выбор уровней (100 карточек, звёзды, замки,
фильтры «Не пройдены» и «Без 3★», счёт звёзд по ступеням), игровой HUD (номер
уровня, ходы, пар, рекорд, пауза, подсказка, отмена, рестарт), экран победы со
звёздами и монетами, магазин, настройки. На первом уровне новичка встречает
короткий урок «Как играть» — его можно открыть заново из паузы. Адаптив под
мобильные: один экран без горизонтальной прокрутки, «безопасные зоны» iPhone,
крупные кнопки, `touch-action: none` на игровом полотне.

**Задача дня.** На главном экране — карточка ежедневного уровня: он выбирается
детерминированно от локальной даты (у всех устройств совпадает, обучение 1–5
не выдаётся, два дня подряд один уровень не выпадает). За первое прохождение
дня начисляется бонус 40–80 монет, серия подряд идущих дней растёт и
продолжается, пока задача решается каждый день; пропуск сбрасывает серию.

**4. Магазин и прогресс.** Монеты за уровни → подсказки, отмены ходов, темы
парковки и наборы цветов машин. Покупки, звёзды, монеты, настройки и текущий
уровень сохраняются в IndexedDB с резервом в localStorage.

**5. Звук и анимации.** Все звуки синтезируются на лету (WebAudio): рокот
двигателя во время перетаскивания, щелчок фиксации, победа, монеты, нажатия,
спокойная фоновая музыка в меню. На устройствах с поддержкой `navigator.vibrate`
есть тактильная отдача: фиксация машины, запрещённый ход, победа, нажатия;
отключается в настройках. Анимации: плавная фиксация машины на клетке,
подсветка доступного коридора, выезд машины за пределы парковки, переходы
между уровнями.

## Спрайты машин

Машины рисуются готовыми картинками (вид сверху, носом вправо) и
перекрашиваются под набор цветов игрока.

```
assets/cars-src/     исходники от художника (нос вверх, прозрачный фон)
  ↓ npm run assets:cars
public/cars/         спрайты для игры: <ключ>.png, <ключ>-long.png, <ключ>-mask.png
```

Скрипт сборки (`tools/build-car-assets.mjs`) поворачивает исходники на 90°,
обрезает по alpha-границам, уменьшает до 384 px по длине, делает «длинные»
варианты для трёхклеточных машин (плавная растяжка середины кузова, 576 px) и
строит маски кузова.

Маска — белая там, где краска, и прозрачная там, где стекло, шины, фары и
обводка. В игре (`src/game/phaser/carPaint.ts`) по маске меняются только
оттенок и насыщенность, а светлота остаётся — поэтому блики и объём кузова
сохраняются, а покупные наборы цветов работают как раньше. Готовые текстуры
кэшируются по ключу `спрайт#цвет`.

Соответствие «кузов → спрайт» и список файлов — в
`src/game/phaser/carSprites.ts`. Целевая машина всегда берёт свой красный
спрайт. Если спрайт отсутствует или не загрузился, сцена рисует машину
вектором (`drawCar.ts`) — игра остаётся играбельной без единой картинки; за
это следят тесты `tests/assets.spec.ts`.

## Архитектура

```
src/
  game/
    core/          чистые функции: правила, столкновения, решатель (BFS)
    levels/        текстовые карты, каталог, generated.ts (100 уровней)
    phaser/        отрисовка: парковка, машины, перетаскивание, сцена
    theme/         палитры оформления парковки и кузовов
  services/        сохранения (IndexedDB/localStorage), звук, адаптер Яндекс Игр
  state/           zustand: игровая сессия, прогресс, интерфейс
  ui/              React: экраны, диалоги, компоненты, стили
assets/cars-src/   исходники спрайтов машин (от художника)
public/cars/       игровые спрайты, собираются `npm run assets:cars`
tools/             генератор уровней, сборка спрайтов, превью кадра
tests/             тесты ядра, уровней, генератора, интерфейса и спрайтов
```

Логика отделена от визуальной части полностью: правила и решатель — чистые
функции без Phaser и DOM; сцена Phaser ничего не хранит, а отображает состояние
из `gameStore`. Поэтому отмена хода, рестарт и подсказки работают без
дублирования кода, а ядро тестируется в Node.

### Связь React ↔ Phaser

`src/game/bridge.ts` — типизированная шина для разовых команд (пауза,
оформление, «сцена готова», «уровень пройден»); игровое состояние живёт в
zustand, к которому сцена подписана напрямую. Phaser подгружается лениво
(`React.lazy`), поэтому в основной бандл не попадает.

## Генератор уровней

`npm run gen:levels` строит уровни так:

1. собирается плотная «решённая» расстановка (целевая машина у выезда);
2. выполняется обход в ширину по графу состояний;
3. от всех решённых состояний считается точное расстояние до победы —
   это и есть пар уровня;
4. берутся состояния, чей пар попадает в диапазон тарифа, путь до победы
   становится готовым решением; всё проверяется по правилам игры.

Результат пишется в `src/game/levels/generated.ts`, промежуточный кэш —
`tools/.cache/levels.json` (можно удалить, уровни пересчитаются).

## Скрытый редактор уровней (админ-панель)

В игре есть невидимая обычному игроку панель, где любой из 100 уровней можно
переставить вручную. Вход:

* пять быстрых нажатий на подзаголовок в главном меню;
* `Ctrl+Shift+A` (или `Cmd+Shift+A`);
* адрес `?admin` или `#admin` — например, `http://localhost:5173/?admin`.

Что умеет панель:

* выбрать уровень 1–100 и поменять его название;
* поставить целевую (красную) машину, горизонтальные и вертикальные машины
  длиной 2–3 клетки, стереть машину ластиком;
* перетаскивать машины вдоль их оси или сдвигать стрелками, отменять и
  возвращать правки (`Ctrl+Z` / `Ctrl+Shift+Z`);
* менять размер поля (5×5…9×9);
* сразу видеть проверку: пересечения, запирание выезда, решаемость и точный
  пар — всё считается тем же решателем, что и в игре;
* видеть, на какие существующие уровни похожа текущая расстановка, и одной
  кнопкой «Найти повторы» получать список похожих пар по всему каталогу
  (помогает убирать повторы);
* сохранить правку, «Сохранить и играть», вернуть исходный уровень,
  экспортировать/импортировать JSON и скопировать готовый блок для
  `generated.ts`.

Правки хранятся в `localStorage` (ключ `parking-jam:custom-levels`) и
подмешиваются в каталог поверх сгенерированных уровней. Кнопка **«Записать в
файл проекта»** на dev-сервере сохраняет их в
`src/game/levels/custom-levels.json` — этот файл можно закоммитить, и уровни
попадут в сборку (в текущей сессии dev-сервер не перезагружается; значения из
файла подхватываются при следующем старте или сборке). Удалённые уровни
запоминаются отдельно, поэтому «Вернуть исходный» не отменяется перезагрузкой.

## Яндекс Игры

SDK **не подключён** — в `index.html` нет внешних скриптов, игра полностью
самостоятельна. Точка интеграции готова: `src/services/yandex.ts` умеет
инициализацию, облачные сохранения (уже встроены в сервис сохранений),
Rewarded Video за подсказки (кнопка «Смотреть» в быстром магазине) и отправку
результата в лидерборд. Чтобы включить — достаточно добавить в `index.html`
`<script src="https://yandex.ru/games/sdk/v2"></script>`: код сам увидит
`window.YaGames`. Без SDK все функции работают как пустышки, ничего не ломая.
